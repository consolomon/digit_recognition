# PartnersFooter

The footer on every page (`partials/_partners.html`): partner lock-ups on a solid black panel, with no border and no label.

- **Entry:** a 64×64 logo, the name, and an underlined `soft` handle.
- **Layout:** entries share the row equally (`flex: 1 1 260px`), each centred, and wrap to new centred rows.
- **Position:** the footer sits at the bottom of short pages.
- **Adding a partner:** add one more `<li class="partner">`.
